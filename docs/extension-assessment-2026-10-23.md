## 적용 경계

| 구분 | 현재 범위 |
|---|---|
| 제공 대상 | 기본 출력 경로를 사용하는 Next.js 배포물 검사와 제한된 소스맵 설정 보호 |
| 위 표의 완료 의미 | 후보별 범위·미확인 조건·재개 기준 평가 완료. 해당 플랫폼 구현·설치·보호 효과 검증 완료가 아님 |
| 기본 설치 | TypeScript 외 새 production dependency, 브라우저 엔진, 난독화 도구, Electron 또는 모바일 SDK를 추가하지 않음 |
| 네트워크 | 기본 정적 검사에는 네트워크 없음. 명시적 loopback 검사, 선택한 프로젝트 build, 설치 준비 및 AI 설명의 경계를 별도로 안내 |
| 금지할 주장 | 역분석·복제·변조 100% 차단, 난독화로 비밀값·서버 인증 문제 해결, 미검증 플랫폼 안전 보장 |
